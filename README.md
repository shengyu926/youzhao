# Youzhao · 有招

**看清局势，聊出办法。**

一个面向豆包工作、Codex、Claude Code和支持自定义技能的Claude网页环境的通用AI Skill，帮助你处理交友、恋爱和亲密关系沟通。先听懂眼前这件事，再看事实和选择；需要回复就给能发的一句，需要练习就陪你一轮轮练。说话跟着你的习惯走，白话、有点幽默，也知道什么时候该认真。

项目名称不限定“恋爱”，当前功能仍集中在关系沟通，不自称全领域专业顾问。

### 豆包导入步骤（更名版待复测）

使用本项目发行的 `youzhao-v0.1.2.zip`。不需要复制长提示词。

1. 进入你的豆包工作环境；普通“对话”入口可能拒绝ZIP。以你实际具有的技能上传/导入入口为准。
2. 上传ZIP，要求“请安装这份Youzhao技能包；若当前环境不支持安装，请明确说明，不要只读取附件后声称安装成功”。
3. 在 `/` 或已安装技能列表检查 `youzhao` / `Youzhao · 有招`。
4. 新开任务，选中有招试一个虚构场景。菜单可见、实际调用、文件读取和档案写入分别验收。

上游适配测试包曾由用户提供豆包安装报告及菜单截图；本次更名后的Youzhao尚未在豆包复测。手机、电脑网页和客户端分别测试，不承诺所有账号都具备同一入口，不承诺永久记忆、自动触发或跨设备同步。不绕过算力限制，不要求为测试先开会员。

项目源码：[shengyu926/youzhao](https://github.com/shengyu926/youzhao)。支持读取GitHub并写入技能目录的本地助手，可请求：

这条是安装请求，不是已经验证所有平台可自动执行的安装器。豆包买家优先使用上面的版本ZIP；Claude网页按账号技能入口上传。

## 档案和更新

必须先得到用户明确同意才启用档案。支持查看、更正、暂停、恢复、撤销、忘记对象和删除；执行依赖宿主Python、文件权限与实际持久存储。没有工具就说明无法保存。

`YOUZHAO_MEMORY_DIR`可指定资料目录；Windows默认使用当前账号应用数据下的youzhao目录，macOS和Linux使用各自用户数据目录。这是买家运行时的行为；本项目开发与测试资料全部放在D盘。存储不在技能安装目录中，重新安装技能不应覆盖档案。

旧goutoujunshi的档案留在旧位置，不自动读取、不自动删除。更名不等于把旧数据迁移成功，详见[更新与旧版迁移](docs/更新与旧版迁移.md)。不要发真实聊天、数据库或验证码给卖家。

## 开发与验证

以下命令用于源码仓库，不是在豆包里执行的安装步骤。Python 3.10及以上，无运行时第三方Python依赖；先建立`tmp`目录，再运行：

```text
python -B -X utf8 -m unittest discover -s tests -v
python -B -X utf8 scripts/build_release.py --output dist
python -B -X utf8 scripts/build_release.py --output dist --layout folder
```

测试检查同意门禁、命名空间、更正/撤销、暂停/删除、旧档案不变及发行包白名单。它们不代替豆包模型行为测试。[平台测试表](docs/平台测试表.md)会明确标出待测项。
