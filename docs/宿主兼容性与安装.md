# 宿主兼容性与安装

核查日期：2026-10-20。Youzhao是通用Agent Skill；共用一份SKILL.md、55份参考和档案脚本。兼容的结构不等于已经在所有宿主实际运行。

## 发行包选择

- `youzhao-v0.2.0.zip`：SKILL.md直接位于ZIP根目录，延续豆包导入试验使用的结构。Codex和Claude Code也可以将它解压到下述名为youzhao的安装目录。
- `youzhao-v0.2.0-folder.zip`：ZIP内含youzhao目录，目录内才是SKILL.md，供Claude网页按其官方“技能文件夹ZIP”流程上传；Codex和Claude Code也可以将其中youzhao目录放入发现目录。

两包只有外层目录布局不同，内核和所有运行文件逐字节一致。不要在同一发现目录装出两份同名技能，也不要将GitHub完整源码ZIP的多层目录直接当成发行包。

## Codex

当前官方文档列出用户级目录`~/.agents/skills`及项目级`.agents/skills`。将有招安装为`<发现目录>/youzhao/SKILL.md`，同级保留references、scripts等内容。已有安装时先核对版本和目录，不直接覆盖或更改全局配置。

可以明确请求“使用youzhao处理这个问题”；显式调用通常使用`$youzhao`。发现与调用以本机实际版本为准。当前会话不刷新时重新启动或新建会话，再检查技能列表。旧版本或已配置环境可能使用其他目录，按宿主现有配置确认，不盲目创建多个副本。

本项目保留`agents/openai.yaml`作为Codex界面元数据；其他宿主不需要执行它。本次仅完成结构、路径与脚本检查，没有将技能安装到用户全局目录，也未进行Codex独立会话模型实测。

官方来源：https://learn.chatgpt.com/docs/build-skills

## Claude Code

个人技能按官方目录`~/.claude/skills/youzhao/SKILL.md`安装；项目技能可用`.claude/skills/youzhao/SKILL.md`。把整个youzhao技能目录放进去，不能只复制SKILL.md丢掉参考和脚本。可在新会话用`/youzhao`尝试明确调用，再核对是否真正加载文件。

个人本地安装不等于已同步到Claude网页或云端任务。Python、读写权限和本地持久存储仍要实际确认；不得把Codex配置当成Claude配置。

官方来源：https://code.claude.com/docs/en/skills

## Claude网页与账号技能

按官方帮助，在具备自定义技能能力的账号中进入`Customize > Skills`，创建/上传技能，选择`-folder.zip`。能否使用受代码执行能力、组织策略及账号界面影响；没有入口时不假定上传普通聊天附件可以完成安装。

本包尚未在Claude网页上传实测。即使技能安装可见，其Python临时执行目录也不能直接当作长期档案；持久化和跨会话读取必须另测。未验证时只沿用当前可用背景，不能说已经永久记住。

官方来源：https://support.claude.com/en/articles/12512180-use-skills-in-claude

## 豆包工作

优先用根目录ZIP，沿用已观察到的导入路径。普通“对话”入口曾在用户截图中拒绝ZIP，需在支持技能的工作环境安装。安装后在`/`或技能列表检查，再新建任务验证实际调用。菜单可见、知识读取和档案持久化分别记录。

旧名goutoujunshi适配包有用户提供的安装报告和菜单截图；Youzhao更名版尚待复测，手机与电脑的支持范围也分别核实。

## 通用档案要求

YOUZHAO_MEMORY_DIR用于明确指定存储位置；不具备环境配置能力时使用脚本的系统默认位置，但必须验证持久性。命令中的脚本位置相对于实际技能根目录。不能把技能安装目录中的样例文件当作用户数据库，发行包不含任何数据库。

不同应用如显式指向同一数据库，也涉及用户同意、访问范围和并发行为，本项目不默认开启。更新保留原存储位置；从旧goutoujunshi迁移仍按独立迁移说明执行，不自动搬动或继承同意。
