# 更新与旧版迁移

## 更新Youzhao

由用户主动选择更新。先确认当前版本与安装位置、查看发行说明，再替换本技能的程序和知识文件。不得删除用户数据目录，不使用清空整个工作区的命令，不把更新包内的样例数据库覆盖真实档案。本项目发行ZIP没有数据库。

新版使用同一个YOUZHAO_MEMORY_DIR或同一默认youzhao用户数据目录，程序升级不更改该位置。升级前仍建议暂停写入并备份；支持情况以宿主持久存储实际行为为准。

## 从goutoujunshi切换

新旧名称不同，可以并存。新技能不会自动读取旧版数据库，也不继承旧版同意状态；先用虚构数据试新版本，再决定是否迁移。

目前没有自动迁移工具，不能仅说“迁移完成”。如需迁移，先确认旧版实际数据位置、旧数据库是否存在和新版是否已有数据；获得用户同意、暂停写入、做可恢复备份，之后再制定操作。两边已有数据时必须逐项处理冲突，不能覆盖或混并对象。

用户不迁移时旧档案原样保留，使用新技能不要求删除旧版。取消旧技能或移除某项档案需要另行明确指令，不能假定更名就允许删除。

## 不属于本项目自动实现的能力

GitHub自动拉取、静默安装、自动跨账号同步、手机自动读取电脑数据库，目前均未实现。发布到GitHub后仍需按平台实际支持的安装和更新方式测试。
