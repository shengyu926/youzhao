# 星座与占星术语：用于话题和自我探索

## 内容性质与使用方法
以下是西方占星的常见象征词汇，是传统文化叙事，不是经过验证的人格测量或关系预测。不同流派有不同解释。把标签变成邀请对方纠正的问题；不要把标签写进对象档案作为事实。用户只要回复一句时，先读星座聊天指南，不先讲完整术语课。

## 十二星座速查
下表按热带黄道的传统分类整理；不以固定公历日期判定交界日的太阳星座。元素和模式是体系内部分类，不能推出个体能力、性别角色或配对结果。

| 星座 | 元素／模式 | 常见象征主题 | 可向本人核实的问题 |
|---|---|---|---|
| 白羊 | 火／基本 | 发起、直接、行动 | 你喜欢直接约，还是先聊熟？ |
| 金牛 | 土／固定 | 稳定、感官、持续 | 一起吃饭和出去探索，你更偏哪种？ |
| 双子 | 风／变动 | 好奇、交流、变化 | 最近有没有突然迷上的东西？ |
| 巨蟹 | 水／基本 | 归属、照顾、熟悉感 | 什么小事会让你觉得被在意？ |
| 狮子 | 火／固定 | 表达、创造、被看见 | 你更喜欢别人夸成果还是夸心思？ |
| 处女 | 土／变动 | 细节、整理、改善 | 约会你喜欢有安排，还是随性一点？ |
| 天秤 | 风／基本 | 协商、审美、平衡 | 遇到分歧你喜欢当场聊还是缓一缓？ |
| 天蝎 | 水／固定 | 深度、信任、隐私 | 熟悉一个人时，你比较看重哪件小事？ |
| 射手 | 火／变动 | 探索、意义、空间 | 如果周末空下来，你最想去哪儿？ |
| 摩羯 | 土／基本 | 责任、规划、持续投入 | 忙的时候，你希望怎么保持联系？ |
| 水瓶 | 风／固定 | 独立、观念、群体 | 有没有一个大家不懂但你很喜欢的爱好？ |
| 双鱼 | 水／变动 | 想象、感受、共鸣 | 最近哪首歌或哪部电影让你有感觉？ |

这些问题是原创沟通素材，不是星座性格证据。选适合当下的一句，不逐项盘问。

## 常见盘面词
- 太阳：占星常用来谈自我表达和认同的象征，不等于完整人格。
- 月亮：常被用来谈感受、熟悉感和安定需求，不是依恋诊断。
- 上升：出生时东方地平线与黄道交点所属星座；需要可靠时刻与地点。不能仅凭生日推算。
- 金星／火星：传统上用于讨论喜好、吸引、表达与行动；不能推出性取向、性意愿或同意。
- 十二宫：盘面的生活领域分区；第一宫常谈自我呈现、第五宫创造与玩乐、第七宫伙伴关系。第七宫不是结婚保证。
- 相位：天体黄经间的特定角度关系。常见合相0°、六合60°、刑90°、拱120°、冲180°；容许度和纳入点由流派及配置决定。
- 逆行：从地球观测的视运动现象；不能据此解释某人失约、操控或突然冷淡。
- 合盘：比较两张盘或另算组合盘的统称；比较盘和组合盘不是同一方法，不生成伪精确缘分分。

热带黄道、恒星黄道、天文学星座边界是不同概念。太阳黄道星座不能用天空所在的天文学星座名称直接替代。天体计算准确与象征解释有效是两回事。
