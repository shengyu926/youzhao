# 星座聊天与轻松接梗

用户问怎么回，先给一句能发的。沿用用户语气，初识不强行撩，认真话题不接烂梗。不默认对方信占星，也不表现成自己知道对方的内心。

## 场景素材：按关系和反馈选用
| 对方原话 | 可发送示例 | 下一步观察 |
|---|---|---|
| 我是处女座，比较挑 | 你主要挑吃的，还是挑陪你吃的人？ | 已有玩笑氛围才用；初识可改“吃饭这方面也挑吗？” |
| 我是天蝎 | 那你自己觉得，哪些说法像你？ | 邀请对方定义自己，不接腹黑或报复标签 |
| 星座你信吗 | 我会拿来聊天，但还得看本人。你觉得你那个准不准？ | 若对方不感兴趣就换话题 |
| 我们星座不合 | 那先看看饭搭子合不合？ | 只在对方愿意玩笑且没有拒绝时用；别把婉拒当挑战 |
| 最近水逆，什么都不顺 | 听着这两天够折腾的。最烦的是哪件？ | 有情绪先听具体事情，不急着科普或逗笑 |
| 我慢热 | 好，那就按舒服的节奏聊。 | 给空间，看是否存在双向联系；不安排追逐套路 |
| 你猜我什么星座 | 我猜不准，要不你给我个线索？ | 不把猜中包装成识人能力 |
| 我喜欢有仪式感 | 你喜欢惊喜，还是提前一起安排？ | 确认具体偏好，再考虑邀约 |
| 你月亮什么 | 我还没核对过，你平时比较看太阳还是月亮？ | 不知道就直说，别编造个人盘面 |
| 我不信这些 | 那不聊星座了。你刚说的那家店叫什么？ | 自然回到对方已有兴趣 |
| 我们没可能，别联系了 | 明白，我尊重你的意思，不再打扰。 | 明确拒绝立即停止，不追加星座梗 |
| 帮我看他是不是花心 | 光看星座看不出来。他做了什么让你有这个担心？ | 回到承诺、透明度及实际行为 |

示例不是群发模板；先看双方熟悉程度、对方是否接梗。对方只回复礼貌短句时，减少密集追问，不连续发送星座测试。

## 从话题到邀约
对方说喜欢美食：问口味，若双方互动积极，可说“你说的那家我也想试，周末有空一起去吗？”给真实时间和可拒绝空间。不要因为对方是金牛就假设爱吃，也不要用合盘、命定或算命索取出生隐私和见面承诺。

## 陪练
用户要练习时读 `references/practical/对话陪练与逐轮反馈.md`，每轮模拟一句，标明是虚构练习。模拟对象不能被写成真实对象的反应。结束再指出哪句接住了话、哪句可能冒犯以及一个更自然的替代。
